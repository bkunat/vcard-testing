Card Link Test

Download links for testing how a device handles contact and calendar files. Each card describes the case it exercises.

  • Full contact files/full-contact.vcf A complete contact with all common fields populated.
  • Minimal contact (name only) files/minimal-contact.vcf A minimal contact — name only (N + FN).
  • Multiple contacts (3 in one file) files/multiple-contacts.vcf Three contacts in one file — only the first is imported; the rest are ignored.
  • Malformed (not a vCard) files/malformed.vcf Not a valid vCard — the payload is plain garbage text.
  • Empty vCard (no usable fields) files/empty.vcf A structurally valid vCard with no usable fields (empty FN).
  • Contact with embedded photo files/with-photo.vcf A contact with an embedded photo (base64 PNG).
  • Contact with a NOTE field files/with-note.vcf A contact with a NOTE field, imported along with the other fields.
  • Unicode name (山田太郎) files/unicode-name.vcf A contact with a non-Latin (Japanese) name.
  • Full contact (.vcard extension) files/full-contact.vcard The same full contact, served with a .vcard extension.
  • URL only (no name) files/url-only.vcf A contact whose only field is a URL — no name, org, phone, email, or address. Should still show the contact card.
  • Birthday only (no name) files/birthday-only.vcf A contact whose only field is a birthday (BDAY) — no name, org, phone, email, or address. Should still show the contact card.
  • Social profile only (no name) files/social-profile-only.vcf A contact whose only field is a social profile (X-SOCIALPROFILE) — no name, org, phone, email, or address. Should still show the contact card.
  • Instant message handle only (no name) files/im-only.vcf A contact whose only field is an instant-messaging handle (IMPP) — no name, org, phone, email, or address. Should still show the contact card.
  • Note only (no name) files/note-only.vcf A contact whose only field is a NOTE — no name, org, phone, email, or address. Should still show the contact card.
  • Photo only (no name) files/photo-only.vcf A contact whose only field is an embedded photo (base64 PNG) — no name, org, phone, email, or address. Should still show the contact card.
  • Full event files/full-event.ics A complete VEVENT with summary, start/end, location, description, organizer, attendee, URL, alarm, and status.
  • Minimal event (summary + start) files/minimal-event.ics The bare minimum — a summary and a start time, no end time, location, or description.
  • All-day event files/all-day-event.ics A single all-day event using a date-only start (VALUE=DATE), no time component.
  • Multi-day event files/multi-day-event.ics A four-day all-day event (a conference) that spans multiple days.
  • Recurring event (weekly) files/recurring-event.ics A weekly recurring event (RRULE), every Monday for 10 occurrences.
  • Event with reminder (alarm) files/event-with-reminder.ics An event carrying a VALARM — a display reminder 30 minutes before it starts.
  • Meeting invite (with attendees) files/meeting-invite.ics A meeting invitation (METHOD:REQUEST) with an organizer and two attendees — may trigger an RSVP flow.
  • Multiple events (3 in one file) files/multiple-events.ics Three events in one file — some apps import all, others only the first.
  • Timezone-aware event files/timezone-event.ics An event in America/New_York with a full VTIMEZONE definition and TZID.
  • Unicode summary (日本語 + emoji) files/unicode-summary.ics An event with a non-Latin summary and an emoji — tests UTF-8 handling.
  • Event with no title (no SUMMARY) files/no-title-event.ics A valid event with no SUMMARY — tests how a missing title is displayed.
  • Cancelled event files/cancelled-event.ics A cancellation (METHOD:CANCEL, STATUS:CANCELLED) of the meeting invite above — same UID, higher sequence.
  • To-do (VTODO, not an event) files/todo.ics A task (VTODO) with a due date instead of a VEVENT — many importers ignore or mishandle it.
  • Empty calendar (no events) files/empty-calendar.ics A structurally valid VCALENDAR that contains no components.
  • Malformed (not iCal) files/malformed.ics Not a valid calendar — the payload is plain garbage text.
