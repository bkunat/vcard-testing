vCard Link Test

Tap a link to download a .vcf / .vcard contact. Each card notes the expected native iOS behavior.

  • Full contact files/full-contact.vcf Native "Add to Contacts" card (iOS 17+). All fields present.
  • Minimal contact (name only) files/minimal-contact.vcf Native "Add to Contacts" card. Only N + FN.
  • Multiple contacts (3 in one file) files/multiple-contacts.vcf QuickLook fallback. Multiple contacts are not supported for native add.
  • Malformed (not a vCard) files/malformed.vcf QuickLook fallback. Payload is garbage, not a valid vCard.
  • Empty vCard (no usable fields) files/empty.vcf QuickLook fallback. Valid structure but no importable data.
  • Contact with embedded photo files/with-photo.vcf Native card showing an embedded photo (base64 PNG).
  • Contact with a NOTE field files/with-note.vcf Native card. NOTE is dropped on import by design; the rest imports fine.
  • Unicode name (山田太郎) files/unicode-name.vcf Native card with a non-Latin (Japanese) name.
  • Full contact (.vcard extension) files/full-contact.vcard Native card. Recognized by the .vcard file extension.
