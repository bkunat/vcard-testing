# vCard & iCal Link Test

The only purpose of this project is to help test contact and calendar file support.
It's a static site serving sample files — open a link to download one and see how the
device handles it. Use the tabs at the top to switch between:

- **vCard** — contact cards (`.vcf` / `.vcard`)
- **iCal** — calendar events (`.ics`)

Each tab lists a set of cases, from a fully populated file down to edge cases
(malformed, empty, unicode, missing fields, and so on).

**Live site (GitHub Pages):** https://bkunat.github.io/vcard-testing/
